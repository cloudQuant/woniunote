## 三、主要发现

### F14-1：仓库中存在已被 Git 跟踪的证书、私钥与备份配置

`git ls-files` 显示 `configs/yunjinqi.top_nginx/*.key/*.pem/*.crt/*.csr` 与 `backups/nginx_*/ssl_certs/*` 已进入版本管理。即使后续从仓库删除，也不能假设这些密钥仍然安全；如果仓库曾推送到远端，必须按泄露处理。

影响：生产 HTTPS 私钥和历史备份配置暴露风险高，优先级高于普通代码优化。

### F14-2：CI 工作流同时保留旧 Flask/Python/PostgreSQL 路径和当前 C++/Vue 路径

当前有三个 workflow：`.github/workflows/ci.yml`、`ci-cd.yml`、`cpp-vue-ci.yml`。其中前两个仍引用旧 `woniunote` Python 包、PostgreSQL、旧脚本或旧覆盖率路径，与当前 README 和代码主线不一致。

影响：质量信号分裂，后续维护者可能误跑旧门禁，甚至在发布前看到与当前栈无关的失败。

### F14-3：测试资产与文档存在明显历史遗留

根目录 `tests/` 中大量用例仍围绕旧 Flask 架构；`tests/test_db/woniunote_test.db` 和 `coverage.json` 已被 Git 跟踪。`REFACTORING_GUIDE.md` 仍描述 FastAPI 方案，而当前主线是 Drogon。

影响：新人或后续 AI 代理会被旧路径误导；测试入口、覆盖率数字和真实门禁之间缺少清晰边界。

### F14-4：前端质量门禁还有可收口噪声

前端 lint 当前 16 个 warning，刚好等于 CI 阈值；Vitest 输出 Vue stub 警告和预期错误日志；构建输出 Rollup 注释警告；E2E 自动 `webServer` 启动在本机超时，但手动预览服务下测试全绿。

影响：门禁虽绿，但噪声过多会降低失败信号的可信度，也使 CI 本地复现不稳定。

### F14-5：依赖审计出现可修复的 PostCSS 中危公告

`npm audit --omit=dev --audit-level=moderate` 报 PostCSS `<8.5.10` 中危 XSS 公告，当前依赖树显示 PostCSS 来自 `vite` 与 `@vue/compiler-sfc`。

影响：这类构建链漏洞不一定进入运行时，但既然可通过 lockfile 更新修复，应作为低风险加固项处理。

### F14-6：后端集成测试本地前置条件不够自解释

集成脚本默认尝试 `root@127.0.0.1:3306` 且无密码，本机失败。CI 里已通过 service container 提供凭据，但本地开发者缺少一条稳定、可复制的运行路径。

影响：后端真实 HTTP 集成测试虽然已经设计好，但本地可用性不足，容易导致回归验证被跳过。

## 四、迭代目标

1. 把仓库里的敏感文件、旧产物和历史测试资产从当前主线治理掉。
2. 让 CI 只表达当前 C++/Vue 主线的质量信号。
3. 把前端 lint/audit/E2E 启动噪声收口，使失败更可信。
4. 让后端集成测试在本地和 CI 都有明确、可复现的入口。
5. 更新文档，使 README、重构指南、测试指南、部署指南与实际主线一致。

## 六、建议实施顺序

1. **先做 Epic 14.1 与 14.2**：敏感文件和 CI 信号是发布可信度基础，优先级最高。
2. **再做 Epic 14.4 与 14.5**：修复可复现的质量噪声和本地测试入口，提升后续开发效率。
3. **最后做 Epic 14.3 与 14.6**：测试资产和文档收口，降低长期维护成本。

建议拆成 2 个开发批次：

- **批次 A（安全与门禁）**：14.1、14.2、PostCSS audit 修复。
- **批次 B（可维护性与文档）**：14.3、14.4 剩余项、14.5、14.6。

## 七、风险与需确认点

1. **证书/私钥轮换范围**：如果这些文件曾推送到公共或多人可访问远端，建议立即轮换；是否重写 Git 历史需要你确认。
2. **旧 Flask 测试是否仍有保留价值**：如果只作为迁移参考，建议归档；如果仍要长期保留，需要明确它不是当前门禁。
3. **CI 旧 workflow 的处理方式**：可以直接删除，也可以先改为 `workflow_dispatch` 手动触发并标记 legacy。建议删除或归档，减少误触发。
4. **E2E 多浏览器策略**：本地默认 Chromium，CI 全矩阵；若本地也要求全矩阵，需要补齐浏览器安装说明。
