## 三、迭代目标

1. 限流真正生效（挂载敏感路由 + 原子化 + fail-closed 可配）。
2. 后端响应统一（公共 Response 工具 + 正确 HTTP 状态码），注册原子化。
3. 评论支持楼中楼（后端返回树状结构，前端渲染回复）。
4. 前端体验：全局 loading + token 无感刷新 + 移动端响应式 + 空状态组件。
5. 测试护栏：前端 Vitest 关键用例 + 后端控制器测试 + GitHub Actions CI。

### Epic 8.1：安全硬化补完（P0-P1，1 sprint）
