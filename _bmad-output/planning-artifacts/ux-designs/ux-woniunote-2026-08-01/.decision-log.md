# Decision Log — Theme System Refresh

## 2026-08-01 — Preserve identifiers, replace the visual contract

- [ASSUMPTION] “Improve the nine themes using industry best practices” means the existing theme identifiers and persisted local-storage values must remain valid, while their visual tokens and selector UI may be redesigned.
- [DECISION] Keep the nine stable keys: `claude`, `notion`, `vercel`, `stripe`, `starbucks`, `linear`, `spotify`, `supabase`, and `sentry`.
- [DECISION] Treat the theme names as visual directions, not as a pixel-for-pixel recreation of third-party brands.
- [DECISION] Every theme declares the same semantic contract: content/surface/text hierarchy, primary default-hover-active states, link states, four feedback colors, `on-*` foregrounds, and a focus color.
- [DECISION] Normal text and filled-action foreground/background pairs are required to reach 4.5:1; visible focus is required to reach 3:1 against the relevant surface.
- [DECISION] The selector must show meaningful miniature hierarchy previews, separate bright and dark choices, and be fully operable from the keyboard.

## Deferred

- Per-user custom palette creation is not part of this iteration.
- A system-preference auto theme is not added because it would introduce a new persistence policy beyond the existing explicit-choice model.
