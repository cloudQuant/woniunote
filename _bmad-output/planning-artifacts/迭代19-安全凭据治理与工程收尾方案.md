## 二、主要发现

### F19-1（P0）：公开仓库中泄露数据库凭据

**事实**：仓库 `cloudQuant/woniunote` 在 GitHub 上为 **PUBLIC**（另有 Gitee 镜像 `yunjinqi/woniunote`），而数据库用户密码 `Woniunote_password1!` 以明文出现在以下**被跟踪**文件中：

| 文件 | 形式 |
|---|---|
| `fix_auth.sql` | `ALTER USER ... IDENTIFIED ... BY 'Woniunote_password1!'` |
| `scripts/check_db.sh` | `DB_PASS="${DB_PASS:-Woniunote_password1!}"` 默认值 |
| `scripts/import_db.sh` | 同上 |
| `scripts/create_math_tables.sh` | 同上 |
| `tests/configs/init_test_db.py` | 明文（2 处） |
| `tests/configs/show_database_info.py` | 明文 |

- `backend_cpp/config.local.json`（本地文件）也含该密码，但**未被跟踪**（✓ 本地安全）。
- 迭代 14 建立的 repo-hygiene 门禁只检查证书/私钥/特定生成物文件，**未覆盖明文口令模式**——这是门禁盲区。
- 影响面：密码本身只在 MySQL 可达时可用（生产 MySQL 通常仅 localhost），但公开凭据违反凭据卫生底线，且构成横向移动的潜在素材。

**处置要求（本迭代核心）**：

1. **轮换密码（必须，用户执行）**：在数据库服务器执行 `ALTER USER 'woniunote_user'@'localhost' IDENTIFIED BY '<新强密码>'`；同步更新所有部署环境（服务器上的 `config.prod.json`、部署脚本使用的环境变量）。轮换后旧密码即失效，历史提交中的明文不再可用——**这是主要缓解手段**（沿用迭代14"不重写 Git 历史"的既定立场）。
2. **仓库侧清理**：删除 `fix_auth.sql`；三个脚本的 `DB_PASS` 默认值改为**无默认（缺失即报错退出）**并从环境变量读取；`tests/configs/*.py` 的密码改为从环境变量读取或随 tests/ 归档一并处理（见 F19-5）。
3. **门禁扩展**：hygiene 步骤新增明文口令模式检查（`IDENTIFIED WITH ... BY '...'`、`password\s*[:=]\s*['"][^'"]{8,}` 等），排除 lockfile 与明确的示例占位符（`CHANGE_ME`/`YOUR_`），当前仓库基线须通过。

### F19-2（P1-P2）：cppcheck style 债 12 条（比迭代16 记录的多 4 条）

CI 门禁口径为 warning/performance/portability（不含 style），当前 style 级残留 **12 条**：

- `controllers/`：AuthController:32、MathTrainingController:50,63、ThumbController:54、UEditorController:52,248,339,395（useStlAlgorithm ×5 + variableScope ×3）
- `core/`：config.cc:102（useStlAlgorithm）、security.cc:308,330,370（constVariableReference ×3）

迭代16 只记录了 controllers 的 8 条；本轮全量扫描发现 core/ 另有 4 条。修复后把 **style 加入 CI 门禁**（基线清零才能加，一次到位）。

### F19-3（P2）：ElementPlus 全量引入，vendor 包 927KB

`main.js` 使用 `app.use(ElementPlus)` + 全量 CSS + **全量图标注册**（`for (Object.entries(ElementPlusIconsVue))`）。`vendor-element-plus` 达 927KB（gzip 293KB），是当前最大非懒加载 chunk。按需引入（`unplugin-vue-components` + `unplugin-auto-import`，或组件级手动引入）通常可削减 60%+；全量图标注册同样应改为按需导入。**风险中等**：改动构建配置与全仓组件的解析方式，需 E2E + 覆盖率全量回归验证。
