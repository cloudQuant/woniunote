# 前端主题体系（迭代 9）

WoniuNote 前端采用「设计令牌驱动的多主题换肤」体系：所有组件只消费一套语义化 CSS 变量（`--wn-*`），主题切换即时生效、可持久化、无需重新编译。

设计令牌来源：[VoltAgent/awesome-design-md](https://github.com/VoltAgent/awesome-design-md)（Google Stitch DESIGN.md 格式）。本项目仅取其公开的设计令牌（颜色/圆角/字体等公开 CSS 数值）与开源替代字体，不使用品牌专有字体与 logo。

## 架构概览

```
DESIGN.md (YAML tokens)
  └─ assets/themes/<key>.css   [data-theme="key"] { --wn-*: ... }   ← 每套主题一个文件
       └─ assets/themes/tokens.css   语义令牌契约（默认值）+ --wn-* → --el-* 映射
            └─ <html data-theme="key" class="dark?">   ← themeStore 控制
                 ├─ stores/theme.js     当前主题 + 持久化 + applyThemeToDom()
                 ├─ config/themes.js    主题清单元数据（key/名称/明暗/色板）
                 ├─ components/common/ThemeSwitcher.vue  导航栏切换入口（九宫格）
                 └─ index.html          首屏防闪烁(FOUC)内联脚本
```

### 关键文件

| 文件 | 作用 |
|------|------|
| `src/assets/themes/tokens.css` | 语义令牌契约 + Element Plus 变量映射；含默认值防 FOUC |
| `src/assets/themes/<key>.css` | 9 套主题，各自 `[data-theme="<key>"]` 覆盖 `--wn-*` |
| `src/assets/themes/index.css` | 统一 `@import`（含 EP 暗色 css-vars） |
| `src/config/themes.js` | 主题清单 `THEMES`、`DEFAULT_THEME`、`THEME_STORAGE_KEY` |
| `src/stores/theme.js` | Pinia 主题 store：`initTheme()` / `setTheme()` / `applyThemeToDom()` |
| `src/components/common/ThemeSwitcher.vue` | 导航栏「主题」按钮 + 九宫格预览面板 |
| `index.html` | 首屏前同步设定 `data-theme`/`dark`，避免白闪 |

## 语义令牌清单（组件应只用这些）

颜色：`--wn-color-primary` / `-primary-hover` / `-primary-active` / `-on-primary`、`-canvas` / `-surface` / `-surface-soft` / `-surface-2`、`-text` / `-text-secondary` / `-text-muted`、`-border` / `-border-strong`、`-link` / `-link-hover`、`-success` / `-warning` / `-error` / `-info`、导航专用 `-nav-bg` / `-nav-text` / `-nav-hover` / `-nav-active`。

其它：圆角 `--wn-radius-sm|md|lg|pill`；阴影 `--wn-shadow-sm|card|lg`；字体 `--wn-font-display` / `--wn-font-body`。

**约定**：组件 `<style>` 内禁止写死颜色/卡片阴影/卡片圆角，一律用上述变量。需要在某主题上有色块叠加（如浅色 tint）时，用 `color-mix(in srgb, var(--wn-color-x) 16%, var(--wn-color-surface))` 以自动适配明暗。

## 如何新增第 10 套主题

1. 在 awesome-design-md 选定一套，复制其 `DESIGN.md` 的 YAML token。
2. 新建 `src/assets/themes/<key>.css`，写 `[data-theme="<key>"] { --wn-*: ... }`（暗色加 `color-scheme: dark;`）。可直接复制一份同明暗的现有主题文件改值。
3. 在 `src/assets/themes/index.css` 增加 `@import "./<key>.css";`。
4. 在 `src/config/themes.js` 的 `THEMES` 数组追加一项（`key/name/desc/dark/swatch`）。
5. 若是暗色主题，需把 `<key>` 加入 `index.html` 防闪烁脚本的 `DARK` 与 `VALID` 映射。
6. `npm run build` 验证；切换器会自动出现新主题。

## 切换器交互

导航栏右侧「主题」按钮 → 点击弹出九宫格面板 → 每格显示色板小样 + 名称 + 明/暗标记，当前主题高亮 → 点击即时应用并写入 `localStorage('wn-theme')`，刷新后保持。首次访问按系统 `prefers-color-scheme` 选明/暗默认（暗→linear，浅→claude）。

## 已知限制

- 富文本编辑器（UEditor）编辑区为同源 iframe，已通过向其内部文档注入主题 `<style>` 实现主题化（见 `UEditor.vue` 的 `applyEditorTheme()`）；工具栏单色图标在暗色主题下用 CSS `filter` 反色（`--wn-editor-icon-filter`）近似处理，非矢量图标故非像素级完美。
- 文章卡片 SVG 占位图取色、进度条/仪表盘状态色为 JS 字面量（状态指示用途），不随主题变化。
- 品牌专有字体（Copernicus/Geist/Circular/SoDoSans 等）不可用，已用开源替代 + 中文系统字体回退。
