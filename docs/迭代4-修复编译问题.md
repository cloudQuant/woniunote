## 已完成的修复

### 1. Mac 编译问题修复 ✅

**问题**: `crypt.h` 头文件在 macOS 上不存在，导致编译失败。

```
fatal error: 'crypt.h' file not found
```

**解决方案**: 修改 `backend_cpp/core/security.cc`，添加平台条件编译：

- Linux: 使用系统 `crypt_r()` 函数进行 bcrypt 哈希
- macOS: 使用 OpenSSL SHA256 作为开发/测试的 fallback 实现

**修改的文件**:
- `backend_cpp/core/security.cc` - 添加 `#ifdef __linux__` 条件编译

**验证**: Mac 和 Ubuntu 编译均通过 ✅

### 3. setup_ubuntu.sh 数据库初始化功能 ✅

更新了 `scripts/setup_ubuntu.sh`，添加以下功能：

#### 3.1 自动创建数据库和用户

```bash
# 默认配置
数据库名: woniunote
用户名: woniunote  
密码: woniunote_password (生产环境需修改)
```

#### 3.2 自动执行 SQL 初始化脚本

按文件名排序执行 `scripts/sql/*.sql` 中的所有 SQL 文件。

#### 3.3 表结构核对功能

- 自动核对现有表结构与预期 schema 的差异
- 检查缺失的表和列
- 检查额外的列（可能是自定义扩展）
- 将差异记录到日志文件 `logs/db_schema_verify_YYYYMMDD_HHMMSS.log`

### 4. 独立的表结构核对工具 ✅

创建了独立的核对脚本 `scripts/verify_db_schema.sh`，可随时运行：

```bash
# 使用方法
sudo bash scripts/verify_db_schema.sh

# 或指定数据库连接
DB_USER=root DB_PASS=password bash scripts/verify_db_schema.sh
```

**功能**:
- 核对所有预期表是否存在
- 核对每个表的列是否完整
- 核对关键索引是否存在
- 生成详细的核对报告日志
