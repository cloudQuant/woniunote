app.utils.ppt_converter module

PPT 转 PDF 工具模块

本模块提供将 PPT/PPTX 文件转换为 PDF 的功能。 支持多种转换方式： 1. Windows: 使用 Microsoft PowerPoint (COM) 或 LibreOffice 2. Linux/Mac: 使用 LibreOffice 或 unoconv

app.utils.ppt_converter.convert_ppt_to_pdf(ppt_path: str, output_dir: str = None) → str[源代码]

将 PPT/PPTX 文件转换为 PDF

尝试使用多种工具（PowerPoint COM, LibreOffice, unoconv）进行转换。

参数:

  • ppt_path -- PPT 文件路径

  • output_dir -- 输出目录，如果为 None 则使用 PPT 文件所在目录

返回:

PDF 文件路径，如果转换失败则返回 None

返回类型:

str
