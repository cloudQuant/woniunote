本模块提供了生成随机渐变背景带文字的缩略图，以及图片压缩功能。 参考 woniunote/common/utils.py 中的 create_thumb_png 函数实现。

app.core.thumbnail.compress_image(source: str, dest: str, width: int, quality: int = 85) → bool[源代码]

压缩图片

调整图片大小并压缩质量。

参数:

  • source -- 源文件路径

  • dest -- 目标文件路径

  • width -- 目标宽度（高度按比例缩放）

  • quality -- 压缩质量 (1-100)

返回:

是否成功

返回类型:

bool

抛出:

  • ValueError -- 当参数无效或文件过大时抛出

  • FileNotFoundError -- 当源文件不存在时抛出
