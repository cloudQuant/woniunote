# WoniuNote 生产环境部署指南

## 🚀 快速部署

### 1. 环境变量配置

在生产环境中，必须设置以下环境变量：

```bash
# 必需的环境变量
export SECRET_KEY="your-secure-secret-key-here"
export DATABASE_URL="mysql+pymysql://username:password@host:port/database_name"

# 可选的环境变量
export REDIS_HOST="localhost"
export REDIS_PORT="6379"
export REDIS_PASSWORD="your-redis-password"
export MAIL_SERVER="smtp.example.com"
export MAIL_USERNAME="your-email@example.com"
export MAIL_PASSWORD="your-email-password"
```

### 2. 使用 Gunicorn 启动应用

```bash
# 基本启动命令
gunicorn -w 3 -b 0.0.0.0:8888 woniunote.app:app

# 推荐的生产环境配置
gunicorn \
  --workers 4 \
  --bind 0.0.0.0:8888 \
  --worker-class sync \
  --max-requests 1000 \
  --max-requests-jitter 50 \
  --timeout 30 \
  --keep-alive 10 \
  --log-level info \
  --access-logfile /var/log/woniunote/access.log \
  --error-logfile /var/log/woniunote/error.log \
  woniunote.app:app
```

### 3. 使用 Nginx 反向代理（推荐）

创建 Nginx 配置文件 `/etc/nginx/sites-available/woniunote`:

```nginx
server {
    listen 80;
    server_name your-domain.com;

    # 静态文件处理
    location /resource/ {
        alias /path/to/woniunote/woniunote/resource/;
        expires 1y;
        add_header Cache-Control "public, immutable";
    }

    # UEditor 资源
    location /ueditor/ {
        alias /path/to/woniunote/woniunote/resource/ueditor/;
        expires 1y;
        add_header Cache-Control "public, immutable";
    }

    # 主应用代理
    location / {
        proxy_pass http://127.0.0.1:8888;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;

        # WebSocket 支持（如果需要）
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";

        # 超时设置
        proxy_connect_timeout 30s;
        proxy_send_timeout 30s;
        proxy_read_timeout 30s;
    }
}
```

启用站点：

```bash
sudo ln -s /etc/nginx/sites-available/woniunote /etc/nginx/sites-enabled/
sudo nginx -t
sudo systemctl reload nginx
```

## 🔧 故障排除

### 常见错误

#### 1. `Failed to find attribute 'app' in 'app'`

**原因**: `app.py` 文件中没有名为 `app` 的变量。

**解决方案**: 确保 `woniunote/app.py` 文件末尾有以下代码：
```python
app = create_app('production')
```

#### 2. 生产环境配置验证失败

**原因**: 缺少必需的环境变量。

**解决方案**: 设置环境变量或修改配置文件。

#### 3. 数据库连接失败

**原因**: 数据库配置错误或数据库服务未启动。

**解决方案**:
- 检查 `DATABASE_URL` 环境变量
- 确保数据库服务正在运行
- 检查数据库用户权限

#### 4. Redis 连接失败

**原因**: Redis 服务未启动或配置错误。

**解决方案**:
- 启动 Redis 服务：`sudo systemctl start redis`
- 检查 Redis 配置
- 设置正确的环境变量

## 📋 系统要求

- Python 3.8+
- MySQL 5.7+ 或 MariaDB 10.0+
- Redis 5.0+ (推荐)
- Nginx (推荐用于反向代理)

## 🔒 安全建议

1. **使用 HTTPS**: 配置 SSL 证书
2. **防火墙**: 只开放必要端口 (80, 443)
3. **定期更新**: 保持系统和依赖包更新
4. **监控**: 设置日志监控和告警
5. **备份**: 定期备份数据库和配置文件

## 📊 性能优化

### Gunicorn 配置优化

```bash
# 高负载环境推荐配置
gunicorn \
  --workers $(nproc) \
  --worker-class gthread \
  --threads 4 \
  --bind 127.0.0.1:8888 \
  --max-requests 1000 \
  --max-requests-jitter 50 \
  --worker-connections 1000 \
  woniunote.app:app
```

### 数据库优化

1. 使用连接池
2. 添加适当的索引
3. 定期清理过期数据
4. 监控慢查询

### 缓存优化

1. 配置 Redis 缓存
2. 设置合理的缓存过期时间
3. 监控缓存命中率
