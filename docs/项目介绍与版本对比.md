## 一、项目简介

### 什么是 WoniuNote？

WoniuNote（蜗牛笔记）不仅仅是一个简单的博客平台，而是一个集文章发布、用户管理、互动交流、个人工具于一体的综合性 Web 应用。

**在线访问**：[https://www.yunjinqi.top](https://www.yunjinqi.top)

### 为什么叫"蜗牛笔记"？

"蜗牛"寓意着脚踏实地、稳步前进。在量化投资领域，成功不是一蹴而就的，需要持续学习、不断积累。就像蜗牛一样，虽然速度不快，但始终在前进，最终能够到达目的地。

### 项目能做什么？

1. **写作与分享** - 发布原创文章、转载优质内容、翻译外文资料
2. **知识管理** - 文章分类整理、收藏喜欢的内容、关键词搜索
3. **互动交流** - 文章评论、多级回复、点赞互动
4. **数学训练** - 口算练习、多难度级别、成绩记录
5. **后台管理** - 文章审核、用户管理、系统监控

## 二、技术架构

### 2.0 版本架构（当前版本）

WoniuNote 2.0 采用**前后端分离**架构：

```
┌─────────────────────────────────────────────────────────────┐
│                         用户浏览器                           │
└─────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────┐
│                     Nginx (反向代理)                         │
│  - HTTPS 加密 (SSL/TLS)                                     │
│  - 静态文件服务 (Vue 构建产物)                                │
│  - 负载均衡 & Gzip 压缩                                      │
└─────────────────────────────────────────────────────────────┘
                    │                    │
          静态资源请求            API 请求 (/api/*)
                    ▼                    ▼
┌──────────────────────┐    ┌──────────────────────────────────┐
│   Vue 3 前端应用      │    │      C++ 后端服务 (Drogon)        │
│  - Element Plus UI   │    │  - RESTful API                   │
│  - Pinia 状态管理    │    │  - JWT 认证                       │
│  - Vue Router 路由   │    │  - bcrypt 密码加密                │
│  - Axios HTTP 请求   │    │  - 异步数据库操作                  │
└──────────────────────┘    └──────────────────────────────────┘
                                         │
                    ┌────────────────────┼────────────────────┐
                    ▼                    ▼                    ▼
           ┌──────────────┐    ┌──────────────┐    ┌──────────────┐
           │   MySQL 8.0  │    │    Redis     │    │  文件存储     │
           │   主数据库    │    │  缓存/限流   │    │  上传文件     │
           └──────────────┘    └──────────────┘    └──────────────┘
```

### 技术选型

| 层级 | 技术 | 说明 |
|------|------|------|
| **前端框架** | Vue 3.4 | 渐进式 JavaScript 框架，组合式 API |
| **UI 组件库** | Element Plus 2.5 | 美观、易用的 Vue 3 组件库 |
| **构建工具** | Vite 5 | 极速的前端构建工具 |
| **状态管理** | Pinia | Vue 3 官方推荐的状态管理库 |
| **后端框架** | Drogon (C++) | 高性能异步 Web 框架 |
| **认证方式** | JWT | JSON Web Token，无状态认证 |
| **密码加密** | bcrypt | 安全的密码哈希算法 |
| **数据库** | MySQL 8.0 | 关系型数据库 |
| **缓存** | Redis 6.0+ | 内存数据库，用于缓存和限流 |
| **Web 服务器** | Nginx | 反向代理、静态文件服务 |

## 三、版本对比：从 1.0 到 2.0 的演进

WoniuNote 经历了一次重大的技术重构，从传统的 Python 全栈应用演进为现代化的前后端分离架构。

### 3.1 架构对比

| 方面 | 1.0 版本 (master) | 2.0 版本 (dev_cpp) |
|------|-------------------|---------------------|
| **后端语言** | Python 3.8+ | C++ 17 |
| **后端框架** | Flask | Drogon |
| **前端技术** | Jinja2 模板 + jQuery | Vue 3 SPA |
| **UI 框架** | Bootstrap | Element Plus |
| **渲染方式** | 服务端渲染 (SSR) | 客户端渲染 (CSR) |
| **API 风格** | 传统路由 | RESTful API |
| **认证方式** | Session | JWT Token |
| **部署方式** | Gunicorn | 原生二进制 + Nginx |

### 3.2 性能提升

C++ 后端相比 Python 后端带来了显著的性能提升：

| 指标 | Python (Flask) | C++ (Drogon) | 提升 |
|------|----------------|--------------|------|
| **请求延迟** | ~50ms | ~5ms | **10x** |
| **吞吐量** | ~1000 req/s | ~5000 req/s | **5x** |
| **内存占用** | ~200MB | ~50MB | **75%↓** |
| **CPU 占用** | 较高 | 较低 | **60%↓** |
| **启动时间** | ~3s | <1s | **3x** |

### 3.4 主要改进

#### ✅ 前端现代化

| 改进 | 说明 |
|------|------|
| **组件化开发** | Vue 单文件组件，代码复用性强 |
| **响应式 UI** | Element Plus 提供美观一致的界面 |
| **状态管理** | Pinia 集中管理应用状态 |
| **路由管理** | Vue Router 实现 SPA 无刷新导航 |
| **热重载** | Vite 开发服务器，修改即时生效 |

#### ✅ 后端高性能

| 改进 | 说明 |
|------|------|
| **异步 I/O** | Drogon 基于事件驱动，高并发处理 |
| **编译优化** | C++ 编译后直接执行，无解释开销 |
| **内存安全** | 现代 C++ 智能指针管理内存 |
| **类型安全** | 编译期类型检查，减少运行时错误 |

#### ✅ 安全性增强

| 改进 | 说明 |
|------|------|
| **JWT 认证** | 无状态 Token，支持分布式部署 |
| **bcrypt 加密** | 安全的密码哈希算法 |
| **HTTPS** | 全站加密传输 |
| **API 限流** | 防止暴力攻击 |
| **CORS 保护** | 跨域请求安全控制 |

#### ✅ 新增功能

| 功能 | 说明 |
|------|------|
| **数学训练** | 口算练习，支持加减乘除四则运算 |
| **点赞系统** | 评论点赞/踩功能 |
| **验证码** | 图形验证码，防止机器人 |
| **系统监控** | 健康检查、数据库状态监控 |

### 3.5 部署方式对比

#### 1.0 版本部署

```bash
# 安装 Python 依赖
pip install -r requirements.txt

# 启动服务
gunicorn -w 3 -b 0.0.0.0:8888 app:app
```

#### 2.0 版本部署

```bash
# 一键启动（开发模式）
bash start_app.sh dev

# 一键启动（生产模式）
bash start_app.sh prod

# 或使用生产脚本
sudo bash scripts/setup_ubuntu.sh   # 首次配置环境
bash restart_app.sh prod            # 启动服务
```

## 四、功能详解

### 4.1 文章系统

文章是博客的核心功能：

- **文章类型** - 支持原创、转载、翻译三种类型
- **分类管理** - 多级分类，灵活归档
- **富文本编辑** - UEditor 编辑器，支持图片上传
- **阅读统计** - 浏览量、评论数统计
- **热门推荐** - 根据阅读量推荐热门文章

### 4.2 用户系统

完整的用户管理功能：

- **注册登录** - 验证码保护，防止恶意注册
- **个人中心** - 修改资料、上传头像
- **密码管理** - bcrypt 加密存储
- **角色权限** - 普通用户、管理员

### 4.3 互动功能

增强用户参与感：

- **评论系统** - 支持多级回复
- **点赞功能** - 评论点赞/踩
- **收藏功能** - 收藏喜欢的文章
- **积分系统** - 活跃度积分奖励

### 4.4 数学训练（新增）

专为家长和孩子设计的口算练习功能：

- **四则运算** - 加法、减法、乘法、除法
- **难度分级** - 简单、中等、困难多个级别
- **计时训练** - 限时答题，训练反应速度
- **成绩记录** - 历史成绩查询

### 4.5 管理后台

管理员专属功能：

- **文章审核** - 审核待发布文章
- **用户管理** - 查看用户列表、管理权限
- **系统监控** - 服务状态、数据库健康检查
- **数据统计** - 访问量、文章数统计

## 五、快速开始

### 环境要求

| 组件 | 版本要求 |
|------|----------|
| 操作系统 | Ubuntu 20.04+ / macOS / Windows |
| C++ 编译器 | GCC 10+ / Clang 13+ / MSVC 2019+ |
| CMake | 3.20+ |
| Node.js | 18+ |
| MySQL | 8.0+ |
| Redis | 6.0+ (可选) |

### 一键启动

```bash
# 克隆项目
git clone https://github.com/cloudQuant/woniunote.git
cd woniunote

# 切换到 dev_cpp 分支
git checkout dev_cpp

# 开发模式（前端热重载）
bash start_app.sh dev

# 生产模式（构建优化）
bash start_app.sh prod
```

### 访问地址

- **前端页面**：http://localhost:8888
- **后端 API**：http://localhost:5173
- **生产环境**：https://www.yunjinqi.top
