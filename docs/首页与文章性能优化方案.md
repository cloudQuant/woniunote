# 首页与文章性能优化方案（可执行清单）

## 目标
- 首页与文章详情首屏P95 < 300ms（服务侧渲染完成）
- 冷启动首开 < 1s；缓存命中首开 < 200ms

## 基线与剖析
1. 为关键路由添加分段耗时打点
   - 首页列表/侧边栏/渲染：woniunote/controller/index.py:54-91
   - 文章详情（优化版）：woniunote/controller/article.py:663-776
2. 启动统一监控并记录请求指标与慢查询
   - 初始化与使用：woniunote/common/unified_monitoring.py:707-716, 622-671
3. 建立基线报告（1天采样），输出P50/P95、命中率、慢查询TOP10

## 路由与数据路径统一
4. 首页与分页统一使用优化方法
   - 列表/统计：ArticlesOptimized.get_articles_page_with_users_cached、get_article_stats_cached
   - 侧边栏：ArticlesOptimized.get_hot_articles_cached
   - 参考：woniunote/controller/index.py:54-75, 198-214
5. 默认文章详情改用优化路由 /article/fast/<id>
   - 兼容原路由但不作为入口：woniunote/controller/article.py:658-796

## 缓存策略（数据+片段）
6. 数据缓存键与TTL（Redis/内存）
   - 列表页 articles_page:{start}:{count} TTL=120s：woniunote/module/articles.py:271-293
   - 详情 article_detail:{id} TTL=300s：woniunote/module/articles.py:296-359
   - 上下篇 prev_next_articles:{id} TTL=300s：woniunote/module/articles.py:507-556
   - 评论聚合 article_comments:{id} TTL=180s：woniunote/module/articles.py:413-469
   - 热门聚合 hot_articles TTL=600s：woniunote/module/articles.py:361-411
   - 统计 article_stats TTL=300s：woniunote/module/articles.py:471-505
7. 片段缓存
   - 首页主体与侧边栏渲染HTML缓存30-60s
   - 文章页顶部信息片段缓存60-120s；评论区仅数据缓存
8. 失效策略
   - 文章新增/编辑：清除 article_detail:{id}、prev_next_articles:*、hot_articles、article_stats 及相关片段
   - 评论新增：清除 article_comments:{id}
   - 使用 CacheManager 前缀清理：woniunote/common/cache_manager.py:121-142, 244-247

## 数据库优化
9. 组合索引（示例）
   - Article：(drafted, checked, articleid)、(drafted, checked, createtime)、(drafted, checked, readcount)、(recommended, drafted, checked, createtime)、(type, drafted, checked, articleid)
   - Comment：(articleid)、(userid)
   - Favorites：(userid, articleid)
   - Credits：(articleid, userid)
10. 查询列裁剪与JOIN优化
   - 列表与热门查询避免Text content；只投影必要列
   - JOIN一次性获取作者/评论用户：woniunote/module/articles.py:313-336, 435-445
11. 连接池
   - 调整SQLAlchemy pool_size、max_overflow；启用预编译和会话归还

## 写入去同步化
12. 阅读数异步累积
