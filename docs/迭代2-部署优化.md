# 迭代2 - 部署优化

## 需求
1. 现在部署的时候 nodejs 的版本是旧的，需要用最新的
2. 现在生产上不能链接github，所以安装不了vcpkg, 优化相应的环境设置，直接在ubuntu上安装需要的包，不再依赖vcpkg，只在测试环境中使用vcpkg。
3. 更新受到影响的部分.

## 已完成的变更

### 1. Node.js 更新到 22.x LTS
- 文件: `scripts/setup_ubuntu.sh`
- 变更: `setup_18.x` → `setup_22.x`

### 2. 移除 vcpkg 依赖，使用系统库
- 生产环境不再依赖 vcpkg，改为从源码编译 Drogon 框架
- **优先使用 `repos/` 目录的本地源码包**，无需联网
- 自动编译安装:
  - **c-ares 1.34.6** (Ubuntu 20.04 自带版本太旧，不支持 ares_getaddrinfo)
  - Drogon v1.9.8
  - Trantor v1.5.21
  - jwt-cpp v0.7.0

### 3. CMakeLists.txt 支持双模式编译
- 新增 `USE_SYSTEM_LIBS` 选项
- **生产环境**: `cmake .. -DUSE_SYSTEM_LIBS=ON` (使用系统库)
- **开发环境**: `cmake .. -DCMAKE_TOOLCHAIN_FILE=...` (使用 vcpkg)

### 4. 更新的脚本文件
| 文件 | 变更 |
|------|------|
| `scripts/setup_ubuntu.sh` | Node.js 22.x, 源码编译 Drogon |
| `scripts/quick_deploy.sh` | 默认使用系统库编译 |
| `scripts/manage.sh` | 默认使用系统库编译 |
| `backend_cpp/CMakeLists.txt` | 支持 USE_SYSTEM_LIBS 选项 |

## 部署说明

### 全新服务器部署
```bash
sudo bash scripts/setup_ubuntu.sh
```

### 已有环境快速更新
```bash
sudo bash scripts/quick_deploy.sh
```

### 离线部署 (无需联网)
源码包已预置在 `repos/` 目录，脚本会自动优先使用本地包：
```
repos/
├── c-ares-1.34.6.tar.gz
├── drogon-1.9.8.tar
├── trantor-1.5.21.tar
└── jwt-cpp-0.7.0.tar
```

### 如果需要更新源码包版本
从以下地址下载并放到 `repos/` 目录:
- **c-ares**: https://github.com/c-ares/c-ares/releases
- **Drogon**: https://github.com/drogonframework/drogon/releases
- **Trantor**: https://github.com/an-tao/trantor/releases
- **jwt-cpp**: https://github.com/Thalhammer/jwt-cpp/releases
